# Experimental Tomb UI assets

These assets are for the hidden experimental `data-ui="tomb"` design path.

They are original model-generated UI artwork prepared for this project and optimized as WebP for mobile delivery. They must not affect the classic UI unless explicitly referenced by Tomb UI code.

## Assets
- tomb-background.webp
- tomb-header.webp
- operative-ready.webp
- operative-selected.webp
- target-selected.webp
- card-disabled.webp
- action-preview.webp
- button-primary.webp
- button-secondary.webp

The mutable labels, operative names, status text, accessibility text, and gameplay state should remain real HTML layered over these graphical assets rather than baked into images.
