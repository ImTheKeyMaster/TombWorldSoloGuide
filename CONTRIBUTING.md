# Contributing to Tomb World Battle Guide

Tomb World Battle Guide is currently maintained as a personal project rather than a community-developed codebase.

## Feedback and bug reports

Bug reports, rules corrections, compatibility reports, UX feedback, and feature suggestions are welcome through GitHub Issues.

When reporting a problem, please include useful details such as:

- Solo or PvP
- Mission
- Kill Team
- Tomb World variant and optional rules
- Turning Point or setup step
- Device and browser when relevant
- Screenshots when useful
- Clear reproduction steps

## Code contributions

External pull requests are not generally accepted.

Please open an Issue first if you have identified a bug or would like to suggest a change. The project owner may choose to implement the idea independently.

Submitting an Issue or Pull Request does not imply that the change will be incorporated into the official Tomb World Battle Guide.

## Official version

The project owner has final discretion over the contents and direction of the official version.
